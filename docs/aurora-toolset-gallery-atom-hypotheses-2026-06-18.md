## Top hypotheses for the live operator

1. Shared palette atom should be learned first: select family icon, select `Standard` or `Custom`, then expand category. This unlocks item, placeable, door, trigger, sound and creature placement workflows.
2. Chest loot atom is the best immediate small-location candidate: select/place a chest, verify `Has Inventory`, open `Inventory ...`, then add one safe standard item only after the dialog is visibly confirmed.
3. Door transition should be split into read-only and mutation atoms: first document existing Door Properties Area Transition state, then test `Setup Area Transition` only on a safe duplicate/test door.
4. Lighting/fog should be previewed before mutation: use `Fog` and `Use Area Lighting` toolbar toggles for visible before/after diffs, then open Area Properties Visual/Environment Options for real saved settings.
5. Tile/group layout is the geometry backbone: use `Groups`/`Terrain` palette preview and paint/undo evidence before chasing Tile Properties; group paint and tile-properties opening remain explicit live gaps.
