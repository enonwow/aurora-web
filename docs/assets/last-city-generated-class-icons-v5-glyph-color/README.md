# Last City class icons v5 glyph color

Stronger glyph-oriented class icon set. Compared with v4, this version uses larger central symbols, fewer character/scene elements, heavier outlines, and sharpened 32x32 exports.

The visual target is the color language of the extracted Last City/GW2-like ability icons, but the symbols are original generated artwork and not direct copies of GW2 assets.

## Files

- `png-32/`: final 32x32 PNG icons.
- `tga-32/`: final 32x32 TGA icons for NWN-style asset use.
- `png-64/`, `png-128/`, `png-256/`: larger review/source sizes.
- `last-city-class-icons-v5-glyph-color-preview-32-zoom.png`: zoomed 32x32 QA preview.
- `last-city-class-icons-v5-glyph-color-preview-128.png`: larger labeled preview.
- `source-generated-sheet.png`: original generated 5x3 sheet.
- `prompt.txt`: final image generation prompt.
