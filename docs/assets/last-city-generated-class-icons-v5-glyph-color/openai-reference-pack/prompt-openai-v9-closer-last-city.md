# OpenAI Prompt: Last City Class Icons v9 Closer Style Match

Use the attached images as references only.

Primary reference priority:
1. The real Last City ability icon sheets are the strongest style reference.
2. The annotated class icon sheet is the composition/reference draft.
3. The output should feel like a class-icon extension of the real Last City ability icons, not like a separate modern icon pack.

Important: any yellow/red hand-drawn circles or marks in the reference are feedback annotations only. Do not include circles, annotations, arrows, labels, handwriting, or markup in the output.

Task:
Create a corrected full 5 columns x 3 rows sprite sheet of 15 original fantasy RPG class icons for a Neverwinter Nights / Last City UI.

Main art direction:
- Make the icons fit Last City more closely.
- Less clean digital gloss, less mobile-game polish, less symmetrical badge perfection.
- More gritty hand-painted NWN/Last City ability icon texture.
- Darker corners, smoky black-brown/black-green/black-blue/black-purple backgrounds.
- Strong central glyphs with rough painted edges.
- High contrast at 32x32, but with slightly aged, worn, dirty fantasy UI surfaces.
- Use the same color-family logic as real Last City ability icons: orange warrior, green tracker, blue scientist, purple trickster.
- Each class icon should look like it belongs in the same HAK next to the extracted `if_*` skill icons.

Hard layout requirements:
- Exact 5 columns x 3 rows.
- 15 equal square tiles.
- Thin dark gutters.
- No text, labels, letters, numbers, logos, watermarks, or annotations.
- No class names anywhere.
- Each icon centered in its tile.
- Each symbol fills about 68-78% of the tile.
- Leave enough dark padding that each icon can be cropped cleanly to 32x32.
- Do not let glow, smoke, weapons, masks, hands, rings, or silhouettes touch tile edges.
- No element may cross tile borders.

32x32 readability requirements:
- Design for 32x32 first.
- One primary symbol per tile.
- Avoid over-detailed faces, tiny ornaments, tiny runes, small bubbles, thin scratch lines, and noisy spark fields.
- Use chunky silhouettes, clear negative space, and thick dark outlines.
- The icon should still read when the full sheet is reduced to 160x96 pixels.

Style match requirements:
- Match the real Last City ability icons more than the current generated class sheet.
- Use rough brush texture, hard rim lighting, and dark vignette corners.
- Avoid overly perfect circular emblems unless the class requires a ring.
- Avoid large clean neon halos that make icons look too modern.
- Avoid pale skin tones and realistic portrait rendering.
- Avoid bright white UI-clean highlights; use warmer metal highlights or cyan magical highlights depending on family.
- Keep materials painterly, not photographic.
- The result should feel older, dirtier, more game-asset-like, and less like pristine concept art.

Targeted fixes from the annotated draft:
- Regenerate the yellow-marked icons completely: Tracker, Hunter, Assassin.
- Fix the red-marked Charlatan icon palette and style.
- Keep the unmarked icons close in motif, but restyle the whole sheet slightly so every icon feels more Last City-native.

- Warrior family: burnt orange, ember, iron, dirty warm steel.
- Tracker family: toxic emerald green, moss-black shadow, muted natural metal.
- Scientist family: cold cyan, blue steel, glass, icy magical light.
- Trickster family: deep violet, magenta, black-purple shadow. Avoid pink skin-tone dominance.
