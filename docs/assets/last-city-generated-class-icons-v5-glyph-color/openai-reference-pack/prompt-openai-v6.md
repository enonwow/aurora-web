Create a new 5 columns x 3 rows sprite sheet of 15 original fantasy RPG class icons for a Neverwinter Nights / Last City UI.

Important output requirements:
- No text, no labels, no letters, no numbers, no logos, no watermarks.
- Exact 5x3 grid, equal square tiles, thin dark gutters.
- Every tile must read clearly when downscaled to 32x32.
- Each icon should be a single bold central glyph/symbol, not a scene and not a character portrait.
- Symbols should fill about 75-85% of each tile.
- Use thick dark silhouettes, bright rim light, strong value contrast, and saturated class-color glow.
- Style should feel like compact hand-painted MMO skill icons: gritty, dark, smoky, high-contrast, Last City/Guild-Wars-2-like color language.
- Do not copy or recreate any existing Guild Wars 2 icon. The artwork and symbols must be original.
- Avoid flat vector clipart, photorealism, tiny details, scenery, full-body characters, and clutter.

Color families:
- Warrior family: orange, iron, ember, steel highlights.
- Tracker family: toxic emerald green, natural shadow, sharp green rim light.
- Scientist family: cold cyan, blue steel, glass highlights.
- Trickster family: violet, magenta, dark shadow.

10. Alchemist: round flask with reagent swirl and bubbles, icy blue glow.
11. Medic: bold medical cross over open palm, cyan healing ring.
12. Engineer: large cog wheel with compact crossbow silhouette inside, blue steel. The gear/crossbow silhouette must be clear at 32x32.
13. Charlatan: theatrical half-mask with one card corner and sand flash, violet glow.
14. Boxer: wrapped fist impact glyph, violet shock ring. No full arm/body.
15. Assassin: dagger under hooded eye crescent, violet shadow. No full character portrait.

Quality target:
