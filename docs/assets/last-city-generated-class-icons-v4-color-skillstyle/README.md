# Last City class icons v4 color skill style

Original generated class icons using the same color language as the extracted class ability icons: orange warrior family, green tracker family, blue scientist family, purple charlatan family.

The icons are not direct copies of Guild Wars 2 assets; they are original symbols made to sit near that high-contrast painted MMO skill-icon look at 32x32.

## Files

- `png-32/`: final 32x32 PNG icons.
- `tga-32/`: final 32x32 TGA icons for NWN-style asset use.
- `png-64/`, `png-128/`, `png-256/`: larger review/source sizes.
- `last-city-class-icons-v4-color-preview-32-zoom.png`: zoomed 32x32 QA preview.
- `last-city-class-icons-v4-color-preview-128.png`: larger labeled preview.
- `source-generated-sheet.png`: original generated 5x3 sheet.
