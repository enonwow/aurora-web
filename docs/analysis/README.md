# Analysis Snapshots

## Purpose
This section stores time-stamped analysis snapshots from source projects used by `aurora-web`.

## Snapshot Rules
1. Every analysis file must include an explicit timestamp.
2. Snapshots are append-only historical records (do not rewrite old snapshots).
3. Each snapshot must contain:
- current state;
- risk analysis;
- identified gaps;
- recommended next actions.

## Naming Convention
1. `aurora-reverse-analysis-YYYY-MM-DD_HH-mm-ss_plusZZZZ.md`
2. `poc-analysis-YYYY-MM-DD_HH-mm-ss_plusZZZZ.md`
