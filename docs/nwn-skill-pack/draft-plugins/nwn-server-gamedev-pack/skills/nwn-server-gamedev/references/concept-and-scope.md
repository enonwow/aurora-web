# Concept And Scope

## What This Domain Controls

Define the server's identity before implementation: genre, player fantasy, RP/action stance, party size, level range, content cadence, wipe policy, death rules, PvP stance, and custom content appetite.

## Design Questions

- What is the core player loop?
- What does a new player do in the first 30 minutes?
- What is the intended long-term progression?
- Which systems must exist at launch, and which can wait?
- Which design decisions are server identity rather than technical convenience?

## Output

Produce a short server charter, a launch-scope list, and a "not yet" list. Mark speculative ideas as `design-only`.
