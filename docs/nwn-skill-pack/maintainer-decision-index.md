# Maintainer Decision Index

## Purpose

Use this index when maintaining `nwn-server-gamedev-pack` and deciding which project artifact or workflow applies next.

This is maintainer handoff material. It is not part of the installed skill and should not be copied into the plugin install boundary.
It covers human feedback, model imports, prompt testing, install-smoke, versioning, and architecture escalation.

## Required Maintenance Loop

After any accepted change to skill references, release tooling, feedback workflow, forward-test scaffolding, install-smoke scaffolding, or package state:

```powershell
python docs\nwn-skill-pack\tools\run_repo_artifact_preflight.py docs\nwn-skill-pack
python docs\nwn-skill-pack\tools\check_release_gate.py docs\nwn-skill-pack --target repo-artifact
```

Use stricter gates only when the package state honestly claims them:

```powershell
python docs\nwn-skill-pack\tools\check_release_gate.py docs\nwn-skill-pack --target release-candidate
python docs\nwn-skill-pack\tools\check_release_gate.py docs\nwn-skill-pack --target install-candidate
```
