## Frozen mutation contract

The source Area detail preserves the exact instance value, including an empty
ResRef. The client stores that immutable value in
`source.placeableOnUsed` and the editable value in
`placeableProperties.scriptSlots.onUsed`. Only a difference between those two
values produces a property mutation.

The backend resolves the retained source identity to one immutable placeable
ordinal and applies this exact operation:

```text
Placeable List[sourceIndex].OnUsed : ResRef = validated onUsed
```

The existing GIT SHA-256 freshness gate still applies. The writer also
requires exactly one `OnUsed` field of type `ResRef`, verifies that its current
value equals the retained `expectedOnUsed`, changes no other GIT field, and
keeps GIC byte-identical unless a simultaneous deletion or addition already
requires a companion rebuild. Independent candidate readback verifies the
new value and preservation of every other field in the mutated struct.

Empty values clear the binding. Non-empty values must match
`[A-Za-z0-9_]{1,16}`. The update cannot target a deleted ordinal, cannot appear
twice for one ordinal, and cannot target another object family.
